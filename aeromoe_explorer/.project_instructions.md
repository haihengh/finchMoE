# AeroMoE Explorer

## Overview
Interactive visualization website for the AeroMoE inference engine (Qwen3.6-35B-A3B on Apple Silicon). Static educational app — no backend/database.

## Design Language
- **Dark theme**: deep navy background (`--background: 222 47% 8%`)
- **Primary**: electric blue (`--primary: 217 91% 60%` → `#3b82f6`)
- **Secondary/Accent**: cyan (`--secondary/accent: 192 91% 42%` → `#06b6d4`)
- **Card**: `222 40% 12%`, glassmorphism with `.glass-card` utility
- **Typography**: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (code)
- Custom utilities: `.glow-blue`, `.glow-cyan`, `.glow-text-blue`, `.glow-text-cyan`

## Structure
- Single-page app with left sidebar navigation + 6 tabs
- All tabs are `"use client"` components in `components/tabs/`
- `AppShell` (client) handles tab state, loaded via `dynamic()` with `ssr: false` from `app/page.tsx`
- `app/page.tsx` is a server component

## Tabs
1. **Overview** — Architecture stack with animated layers, signal pulse, detail panel
2. **Inference Pipeline** — 9-step animated token generation walkthrough
3. **MoE Routing** — Interactive 128-expert grid with top-8 routing, LFU cache simulation, auto-mode
4. **Memory Manager** — SVG gauge (0–4 GB), context length slider, expert loader, breakdown bars
5. **Tool-Calling** — Agentic flow diagram with 10-step demo, code snippet panel
6. **File Explorer** — 38-file tree grouped by session, search, detail drawer

## Data
- All static model data in `lib/data.ts` — MODEL_CONFIG, SOURCE_FILES, ARCHITECTURE_LAYERS, PIPELINE_STEPS, TOOL_CALL_DEMO_STEPS
- `grid-cols-16` added to tailwind.config.ts for MoE expert grid

## Key Technical Decisions
- No ThemeProvider (dark-only app, CSS variables set once in `:root`)
- No database, no API routes
- Framer Motion for all animations
- Recharts NOT used (all visualizations are custom SVG/CSS)
